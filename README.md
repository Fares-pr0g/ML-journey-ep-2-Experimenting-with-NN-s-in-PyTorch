# 🧠 Deep Learning with PyTorch — My Learning Journey

> A hands-on journey into Deep Learning with PyTorch — learning by implementing, experimenting, breaking things, and trying again.

This repository documents my exploration of **Deep Learning with PyTorch** throughout the summer of 2026.

Rather than simply following tutorials, I used this repository to **implement concepts from scratch, experiment with architectures, analyze results, and document what I learned along the way.**

The goal was simple:

**Learn → Implement → Experiment → Understand**

---

## 🚀 What I've Explored

The repository follows my progression from the fundamentals of neural networks toward sequence modeling and language models.

### 🔹 1. PyTorch & Neural Network Fundamentals

Building a solid foundation in PyTorch and understanding the mechanics behind neural networks.

Topics include:

- Tensors and tensor operations
- `Dataset` and `DataLoader`
- `nn.Module`
- Linear layers
- Activation functions
- Loss functions
- Optimizers
- Training and evaluation loops
- Model evaluation and experimentation

---

### 🔹 2. Computer Vision & CNNs

Moving from basic neural networks to **Convolutional Neural Networks (CNNs)** and image classification.

Topics and experiments include:

- Convolutional layers
- Pooling
- Feature extraction
- CNN architectures
- Data augmentation
- Training and evaluation
- **TinyVGG**
- Image classification experiments

---

### 🔹 3. Transfer Learning

Exploring how pretrained models can be adapted to new problems.

Topics include:

- Pretrained neural networks
- Feature extraction
- Fine-tuning
- Applying transfer learning to image classification

---

### 🔹 4. Recurrent Neural Networks

Moving from spatial data to **sequential data**.

Topics include:

- RNNs
- Hidden states
- Sequence modeling
- Text preprocessing
- Embeddings
- Sentiment classification

---

### 🔹 5. LSTMs & Sequence Modeling

Exploring how **Long Short-Term Memory (LSTM)** networks address some of the limitations of traditional RNNs.

Experiments include:

- LSTM architecture
- Embedding layers
- Variable-length sequences
- Padding and packed sequences
- Sentiment analysis
- Model training and evaluation

---

### 🔹 6. Character-Level Language Modeling

Taking the first steps toward language generation by building a **character-level language model**.

This section explores:

- Character tokenization
- Sequence generation
- RNN-based language modeling
- Sampling
- Text generation
- Understanding how models learn patterns in sequences
